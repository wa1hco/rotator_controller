# ADR 0014: STM32F407VGT6 and a LAN8720A, with Ethernet standard

- Status: Accepted
- Date: 2026-10-11

## Context

The imported V4 schematic uses an STM32F405RGT6 in LQFP-64 (LCSC C15742).
That part has no Ethernet MAC. ST does not make an STM32F407 in a 64-pin
package. On 2026-10-11 the F405RGT6 showed zero stock at both JLCPCB and
LCSC, so the board as drawn cannot be assembled there. The earlier plan
treated Ethernet as an optional W5500 on SPI. That path is a poor fit
once the MCU has to change package anyway.

Part stock, prices, and the RMII pin table are in
`docs/design/mcu-ethernet-lcsc.md`. Stock moves; recheck before ordering.
The Pulse jack's Mouser stock was not confirmed live.

## Decision

Ethernet is standard on every board. The W5500 path is dropped.

| Function | Part | Source field |
|---|---|---|
| MCU | STM32F407VGT6, LQFP-100, LCSC C12345 | `LCSC` = C12345 |
| RMII PHY | LAN8720A-CP-TR, LCSC C45223. LAN8742A-CZ-TR (C621424) is the same footprint if the LAN8720A is unavailable | `LCSC` |
| PHY clock | 25 MHz crystal X322525MOB4SI, LCSC C9006 (JLCPCB Basic). The PHY PLL supplies the 50 MHz REF_CLK. No separate 50 MHz oscillator | `LCSC` |
| USB ESD | USBLC6-2SC6, LCSC C7519, on D+/D- | `LCSC` |
| Ethernet ESD | SRV05-4, LCSC C13612, on the PHY side of the MagJack | `LCSC` |
| RJ45 | Through-hole MagJack, hand-soldered, bought from Mouser. Candidate: Pulse J0011D01BNL. Not confirmed | `Mouser` |

ADR 0007's earlier "Ethernet optional" wording is superseded by this
decision. USB stays required.

The V4 MCU area was barely started, so a re-layout onto LQFP-100 is
acceptable. This decision does not edit the KiCad schematic or PCB. The
files in `hardware/controller/` still show the F405RGT6.

## Consequences

The firmware target is the STM32F407VGT6. The C++ core stays
processor-agnostic; only the board bring-up and `platformio.ini` name
this part. RMII uses the LQFP-100 PB transmit pins, because port G is
not bonded on that package. About ten ADC inputs remain after RMII,
which covers two axes. The next schematic edit places these parts and
fills the `LCSC` and `Mouser` fields from ADR 0013.
